# Что нужно, чтобы довести Motion Studio до продакшн-уровня

Дата: 06.05.2026  
Проект: Motion Studio / Kimodo  
Цель: сделать из текущего прототипа стабильный продукт для регулярной работы с 3D-анимацией, моделями движения и USD-сценами.

## 1. Что уже есть

- Локальный запуск интерфейса на `127.0.0.1:7860`.
- Базовая генерация движения через Kimodo SOMA SEED.
- Загрузка и выгрузка моделей из памяти при запуске и генерации.
- CPU-режим для текстового энкодера, чтобы меньше забивать VRAM.
- Русский интерфейс без лишних логотипов.
- Черная тема по умолчанию.
- Иконки для основных действий.
- Загрузчик USD 3D.
- Синхронизация длины дорожек таймлайна с длиной анимации.
- Git-ветка `dev` и локальный репозиторий `nein3d`.

- Сделать один launcher для Windows: запуск text encoder, запуск UI, проверка портов, проверка GPU.

- Развести логи: интерфейс, модель, текстовый энкодер, генерация, импорт/экспорт.

- Сделать компактную панель инструментов с иконками.
